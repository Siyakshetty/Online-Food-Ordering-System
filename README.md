\# Online Food Ordering System



A full-stack online food ordering website built using FastAPI, SQLAlchemy, SQLite, HTML, CSS, and JavaScript.



\## Features



\- Restaurant listing

\- Restaurant search

\- Restaurant menu

\- Food customization

\- Add to cart

\- Increase/decrease quantity

\- Checkout

\- Order placement

\- Order confirmation

\- SQLite database

\- FastAPI backend

\- Responsive frontend



\## Tech Stack



\- Python

\- FastAPI

\- SQLAlchemy

\- SQLite

\- HTML

\- CSS

\- JavaScript
